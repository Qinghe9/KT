# 论文实验部分最终审查（2026-11-07）

## 1. 审查结论

当前实验方案的核心设计是合理的：数据按学生划分，训练、验证和测试学生互斥；知识追踪和WeakKC均使用原子知识点；测试阶段不使用滑动窗口；WeakKC候选样本由固定的历史比例、未来支持次数和错误率阈值生成；模型选择仅依据验证集；测试集不参与早停或超参数选择。

但是，当前Word论文尚不能作为最终提交版本。主要原因不是实验方案错误，而是论文中的若干表格、图和文字仍引用旧结果，且基线的随机种子聚合方式不统一。

综合判定：**实验方案通过，Algebra主实验统一协议通过，论文结果呈现暂不通过。**

## 2. 已确认正确的实验协议

- 划分单位：学生，而非交互记录。
- 划分比例：训练集、验证集、测试集约为8:1:1。
- 划分种子：1024。
- 训练随机种子：2026和3407。
- 最大序列长度：200。
- 测试方式：非滑动窗口。
- 知识点表示：原子KC；多知识点题目采用掩码平均嵌入，不拆分为多条独立作答记录。
- WeakKC历史比例：0.7。
- 最小历史交互数：16。
- 每个候选知识点的最小未来作答数：10。
- 薄弱阈值：未来错误率不低于0.6。
- 非薄弱阈值：未来错误率不高于0.4。
- 模糊区间：(0.4, 0.6)，不参与WeakKC监督和评价。
- 主指标：AUC、ACC、RMSE、Macro-KCAUC、WeakKC-AUC、Recall@1/3/5/10。

### 4.3 Algebra两阶段训练尚未统一

论文表5-4中的Algebra KT-only、Joint Training和Two-stage WeakHead结果来自旧测试口径：标准KT样本数为51123，WeakKC候选数为497。新的主实验口径分别为51067和559。

### 4.4 Algebra消融实验尚未统一

现有Algebra消融预测均使用旧口径（KT为51123，WeakKC为497），而新Full结果使用51067和559。因此表6-2和图6-1中的Algebra消融比较尚不满足同一测试集合要求。

处理方式：在统一候选清单上重新评估全部消融检查点，并将上述6项seed 3407实验以batch size 4096重跑；或者从主论文移除Algebra消融，只保留已满足严格协议的数据集消融。

## 6. 可以成立的结论

在完成表图更新后，以下结论有证据支持：

1. 本文模型能够在五个数据集上完成下一题正确率预测和WeakKC诊断。
2. 本文模型并非在所有数据集、所有指标上最优，因此应表述为“具有较好的综合性能”，不能表述为“全面优于所有基线”。
3. 在统一后的Algebra结果中，本文模型AUC略低于DIMKT，但ACC、RMSE、Macro-KCAUC均优于表中其余代表性方法；WeakKC-AUC低于SAINT，但高于其他所列代表性基线。
4. 四个原数据集的两阶段训练结论可在相同候选口径下讨论；Algebra需完成统一评估后再纳入该结论。
5. ASSIST2009和EdNet的消融可以作为主要模块有效性证据；Algebra消融在完成统一前只能视为旧实验记录，不能作为最终论文证据。
